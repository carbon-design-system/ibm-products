# Tearsheet (New Composable)

> 💡 This is the new composable tearsheet component with enhanced features including stacking support, collapsible headers, responsive and improved composability.

[Usage guidelines](https://pages.github.ibm.com/carbon/ibm-products/components/tearsheet/usage/)

## Overview

A tearsheet is a mostly full-screen type of dialog that keeps users in-context and focused by bringing actionable content front and center while revealing parts of the UI behind it. There is also a narrow variant of the tearsheet.

A tearsheet is composed of up to five zones, providing flexibility based on the content: a heading area, an optional navigation area positioned just below the heading, an optional influencer area on the left, a main content area, an optional summary details area on the right, and a footer section.

The implementation is designed to deliver a composable tearsheet that’s both feature-rich and highly customizable. In web components this is achieved through a slot-based composition model with distinct sections.

By default, the tearsheet is controlled through the `open` attribute on `c4p-preview-tearsheet`.



The next-generation tearsheet uses a slot-based composition model with the following sub-components:
- **`c4p-preview-tearsheet`** - Main container
- **`c4p-tearsheet-header`** - Header section
- **`c4p-tearsheet-header-content`** - Header content area
- **`c4p-tearsheet-navigation-bar`** - Rendered at the bottom of the header and can render tabs
- **`c4p-tearsheet-scroller`** - Can be used inside the navigation bar as a trigger to collapse or expand the header
- **`c4p-tearsheet-body`** - Main content area
- **`c4p-tearsheet-influencer`** - Left-side panel for contextual content
- **`c4p-tearsheet-footer`** - Footer with actions

## Available Slots

### Main Tearsheet (`c4p-preview-tearsheet`)

| Slot | Component | Description |
|------|-----------|-------------|
| `header` | `c4p-tearsheet-header` | Header section with title and actions |
| `influencer` | `c4p-tearsheet-influencer` | Left-side panel for contextual info |
| `body` | `c4p-tearsheet-body` | Main content area |
| `footer` | `c4p-tearsheet-footer` | Footer with action buttons |

### Header (`c4p-tearsheet-header`)

| Slot | Component | Description |
|------|-----------|-------------|
| `header-content` | `c4p-tearsheet-header-content` | Main header content (title, description) |
| `header-navigation` | Any | Navigation tabs or breadcrumbs |
| `header-actions` | `cds-button` | Action buttons (e.g., settings, delete) |
| `decorator` | `cds-ai-label` | AI label or decorative elements |

### Header Content (`c4p-tearsheet-header-content`)

| Slot | Component | Description |
|------|-----------|-------------|
| `label` | Any | Optional label text above title |
| `title-start` | Any | Content before title (e.g., icons) |
| `title-end` | Any | Content after title (e.g., badges) |
| `description` | Any | Custom description content |
| `decorator` | `cds-ai-label` | AI label or decorative elements |

### Body (`c4p-tearsheet-body`)

| Slot | Component | Description |
|------|-----------|-------------|
| `main-content` | Any | Primary content area |
| `summary-content` | `c4p-tearsheet-summary-content` | Right-side panel for summary |


## Key Features

- **Scalable & Composable**: Built with composable subcomponents that can be easily extended and customized for different use cases
- **Collapsible Header**: Smart header that automatically collapses on scroll to maximize content space and can be disabled via the `disable-header-collapse` attribute on `c4p-tearsheet-header`
- **Better Developer Experience**: Clear component boundaries through named slots and dedicated subcomponents
- **Responsive Layout**: Influencer and summary content can move into side panels on small screens and narrow tearsheets
- **Stacking Support**: Multiple tearsheets can stack when wrapped in `c4p-tearsheet-stack`

## Stacking Tearsheets

To enable stacking for multiple tearsheets, wrap them in a `<c4p-tearsheet-stack>` component. This opt-in approach provides better performance and explicit control over which tearsheets participate in stacking. The `stack-step-size` attribute controls the visual offset between stacked tearsheets (`sm`, `md`, or `lg`).

```html
<c4p-tearsheet-stack stack-step-size="lg">
  <!-- First tearsheet -->
  <c4p-preview-tearsheet id="tearsheet-1" open>
    <c4p-tearsheet-header slot="header">
      <cds-button slot="header-actions">
        Open details
      </cds-button>
    </c4p-tearsheet-header>
    <!-- ... -->
  </c4p-preview-tearsheet>

  <!-- Second tearsheet - will stack on top -->
  <c4p-preview-tearsheet id="tearsheet-2" open>
    <!-- ... -->
  </c4p-preview-tearsheet>
</c4p-tearsheet-stack>
```

## Collapsible Header

The header automatically collapses when scrolling in the main content area. To disable this behavior:

```html
<c4p-tearsheet-header slot="header" disable-header-collapse>
  <!-- Header will not collapse on scroll -->
</c4p-tearsheet-header>
```

## Footer Actions

The `c4p-tearsheet-footer` component supports two approaches for rendering action buttons:

**Using the `.actions` property (recommended):**

```html
<c4p-tearsheet-footer
  slot="footer"
  .actions="${[
    {
      kind: 'ghost',
      label: 'Cancel',
      onClick: () => setOpen(false),
    },
    {
      kind: 'secondary',
      label: 'Back',
    },
    {
      kind: 'primary',
      label: 'Submit',
    },
  ]}">
</c4p-tearsheet-footer>
```

**Using custom buttons:**

```html
<c4p-tearsheet-footer slot="footer">
  <cds-button kind="ghost">Cancel</cds-button>
  <cds-button kind="secondary">Back</cds-button>
  <cds-button kind="primary">Submit</cds-button>
</c4p-tearsheet-footer>
```

The `.actions` property automatically handles button sizing based on the tearsheet variant and screen size, while custom buttons give you full control over the footer layout.
