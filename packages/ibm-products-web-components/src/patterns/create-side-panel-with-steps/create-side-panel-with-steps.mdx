## Overview

The `create-side-panel-with-steps` is a **pattern** (not a component) that
provides a recipe for building multi-step creation flows inside a side panel.
It combines `c4p-side-panel` with the `StepInstance` step utility and a
**horizontal** `cds-progress-indicator` placed in the panel's `slot="below-title"`
to guide users through a sequential form workflow while keeping on-page content
visible.

Use this pattern for **medium-complexity creations** where the user needs page
context. The side panel appears on top of existing page content, which remains
accessible.

## What is a Pattern?

Unlike components that are exported from the package, **patterns are recipes**
that you copy into your codebase and customize to fit your specific needs. This
approach offers:

- **Full Control**: Modify the code to match your exact requirements
- **No Breaking Changes**: Updates to the pattern don't affect your
  implementation
- **Seamless Customization**: Adapt the pattern without workarounds or prop
  drilling
- **Scalability**: Build upon the foundation with your own features

The `create-side-panel-with-steps` pattern consists of:

- `utils/step-instance.ts` — Copy of the `StepInstance` step utility (backed by `@lit-labs/signals`)
- `components/create-side-panel-step.ts` — Individual step web component
- `create-side-panel-with-steps.ts` — Wrapper example wiring everything together

## Architecture

The pattern is built on top of:

- **`StepInstance`**: A reactive step utility (copied into `utils/step-instance.ts`) backed by `@lit-labs/signals`. Provides `currentStep`, `totalSteps`, `formState`, `handleNext()`, `handlePrevious()`, and `reset()`.
- **`SignalWatcher`** (`@lit-labs/signals`): Applied to the host component so that changes to the `StepInstance` signal automatically trigger re-renders.
- **`c4p-side-panel`**: The IBM Products side panel that hosts the step content and action buttons.
- **Horizontal `cds-progress-indicator`**: Placed in `slot="below-title"` of the side panel — this renders the steps directly below the panel title as a horizontal progress bar, matching the Carbon side panel step-flow pattern.

### Step Management

Steps are managed entirely through `StepInstance`. The pattern gives you:

| API | Purpose |
|---|---|
| `_stepInfo.data.currentStep` | 0-based index of the active step |
| `_stepInfo.data.totalSteps` | Total number of steps |
| `_stepInfo.data.formState` | Shared form state object across all steps |
| `_stepInfo.handleNext()` | Advance to the next step |
| `_stepInfo.handlePrevious()` | Go back to the previous step |
| `_stepInfo.reset()` | Reset to step 0 and clear form state |
| `_stepInfo.updateFormState =` | Replace shared form state (use `structuredClone` before mutating) |
| `_stepInfo.updateTotalStepCount =` | Set the total step count (call in `connectedCallback`) |

Your wrapper component tracks step state via `StepInstance` and conditionally renders each step using `lit/nothing` — only the active step's markup is in the DOM.

### Horizontal progress indicator placement

The `cds-progress-indicator` is rendered in `slot="below-title"` on `c4p-side-panel`. This places it
directly below the panel title as a horizontal strip, matching the pattern shown in the [Step flows utility story](https://ibm-products-web-components.netlify.app/?path=/story/utilities-step-flows--side-panel-with-steps).

Step states are driven from `currentStep`:

```ts
state=${index < currentStep ? 'complete'
      : index === currentStep ? 'current'
      : 'incomplete'}
```

### Key Implementation Steps

1. **Copy utilities** — Copy `utils/step-instance.ts` and `components/create-side-panel-step.ts` into your project.
2. **Extend `SignalWatcher`** — Wrap your component class with `SignalWatcher(LitElement)` so signal changes trigger re-renders.
3. **Initialize `StepInstance`** — Create a private `_stepInfo = new StepInstance()` and call `_stepInfo.updateTotalStepCount = n` in `connectedCallback`.
4. **Render horizontal progress indicator** — Place `<cds-progress-indicator>` inside `slot="below-title"` on the side panel; map `_stepLabels` to `<cds-progress-step>` elements.
5. **Render steps conditionally** — Use `currentStep === n ? this._renderStepN(fs) : nothing` to show only the active step.
6. **Save form state** — Use `structuredClone(this._stepInfo.data.formState)`, mutate the clone, then assign back with `this._stepInfo.updateFormState = clone`.
7. **Wire action buttons** — Use `slot="actions"` buttons on `c4p-side-panel` for Cancel / Back / Next / Create navigation.

#### TypeScript

```typescript
import { LitElement, html, nothing } from 'lit';
import { state } from 'lit/decorators.js';
import { SignalWatcher } from '@lit-labs/signals';
import { carbonElement as customElement } from '@carbon/web-components/es/globals/decorators/carbon-element';
import { StepInstance } from './utils/step-instance';

@customElement('my-create-side-panel')
class MyCreateSidePanel extends SignalWatcher(LitElement) {
  @state() private _open = false;

  private _stepInfo = new StepInstance();
  private readonly _stepLabels = ['Step 1', 'Step 2', 'Step 3'];

  connectedCallback() {
    super.connectedCallback();
    this._stepInfo.updateTotalStepCount = this._stepLabels.length;
  }

  render() {
    const { currentStep, totalSteps } = this._stepInfo.data;
    const isLastStep = currentStep + 1 === totalSteps;

    return html`
      <cds-button @click=${() => (this._open = true)}>Create</cds-button>

      <c4p-side-panel
        ?open=${this._open}
        title="Create resource"
        include-overlay
        ?animate-title=${false}
        @c4p-side-panel-closed=${() => { this._open = false; this._stepInfo.reset(); }}
      >
        <div slot="subtitle">Specify the resource details</div>

        <div slot="below-title">
          <cds-progress-indicator>
            ${this._stepLabels.map((label, index) => html`
              <cds-progress-step
                label=${label}
                state=${index < currentStep ? 'complete'
                      : index === currentStep ? 'current'
                      : 'incomplete'}
              ></cds-progress-step>
            `)}
          </cds-progress-indicator>
        </div>

        ${currentStep === 0 ? html`<p>Step 1 content</p>` : nothing}
        ${currentStep === 1 ? html`<p>Step 2 content</p>` : nothing}
        ${currentStep === 2 ? html`<p>Step 3 content</p>` : nothing}

        <cds-button slot="actions" kind="ghost"
          @click=${() => { this._open = false; this._stepInfo.reset(); }}>
          Cancel
        </cds-button>
        <cds-button slot="actions" kind="secondary"
          ?disabled=${currentStep === 0}
          @click=${() => this._stepInfo.handlePrevious()}>
          Back
        </cds-button>
        <cds-button slot="actions"
          @click=${() => isLastStep
            ? (this._open = false, this._stepInfo.reset())
            : this._stepInfo.handleNext()}>
          ${isLastStep ? 'Create' : 'Next'}
        </cds-button>
      </c4p-side-panel>
    `;
  }
}
```
